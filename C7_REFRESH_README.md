# AdMatera MAPS C7 Refresh

Last modified: 2026-09-08 11:45 CDT (UTC-05:00)

Server-side refresh tooling for AdMatera MAPS C7.

- Validates current water observations before publication.
- Retains the last validated snapshot when a refresh fails.
- Keeps credentials and live data-provider requests out of the visitor bundle.

Operational records and release decisions are maintained outside this public cache repository. Never commit credentials or local environment files.
